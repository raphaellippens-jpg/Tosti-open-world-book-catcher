# Bookbound — The Wild Pages 📚

A colorful, responsive open-world book-catching browser game built with plain HTML, CSS, and JavaScript.

## GitHub Pages
1. Upload all project files to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.

## Controls
- On-screen arrows or WASD/arrow keys to move.
- Tap the map to move directly to a spot.
- Catch a book when close enough.
- Spacebar to catch, plus/minus to zoom.
- Progress saves in localStorage on this browser/device.

## Features
- 50 collectible books, each with a unique name and mini-story.
- Five rarity tiers: Common, Uncommon, Rare, Epic, Legendary.
- Coin rewards: 5, 9, 16, 30, and 75 coins by rarity.
- Six colorful biome zones and discoverable places.
- Responsive layout, touch controls, local autosave, and reset.
